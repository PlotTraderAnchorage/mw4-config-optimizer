## 📖 Overview

Modern Warfare 4 pushes PC hardware to the limit, but its default configuration often leaves performance on the table. Frame drops, inconsistent pacing, and shader compilation stutters can ruin the experience, even on high-end systems.

**MW4 Config Optimizer** is a lightweight, native Windows utility that safely adjusts game configuration files and Windows settings to ensure the smoothest possible gameplay.

### ⚡ Key Features

| Feature | Description |
|:---|:---|
| **FPS Optimization** | Adjusts rendering threads and VRAM allocation to prevent GPU bottlenecks. |
| **Stutter Elimination** | Cleans and pre-allocates shader caches for consistent frame delivery. |
| **Network Tweaks** | Optimizes Windows TCP settings for lower latency in multiplayer. |
| **Safe & External** | Operates purely on configuration files. No injection, no anti-cheat flags. |
